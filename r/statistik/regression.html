Regression, forudsigelser og residualer

Tilpasse en lineær model, lave en forudsigelse og fortolke en justeret koefficient.

Statistik med R · 25 minutter

Efter øvelsen kan du tilpasse en lineær model, lave en forudsigelse og fortolke en justeret koefficient.

Dataene er små øvelsesdata eller datasæt, der følger med de anvendte pakker.

Vent på R, redigér feltet, og vælg Run Code. Første indlæsning af motor og pakker kan tage lidt tid. Start Over gendanner feltets kode; genindlæsning nulstiller hele sidens session. Kode og svar gemmes ikke. Brug punktum i numeriske svar.

1. Forudsig og vælg

Hvad betyder lm(dist ~ speed, data = cars)?

2. Arbejd selv

Tilpas dist ~ speed til cars. Find hældningen, og forudsig dist ved speed = 20. Tegn residualerne mod de forudsagte værdier. Tilpas også mpg ~ wt + hp til mtcars og undersøg koefficienterne.

Skriv dine resultater nedenfor. Tjek svar kontrollerer svarfelterne, ikke din kode.

Hældning i cars-modellen? Brug to decimaler.

Forudsagt dist ved speed = 20? Brug to decimaler.

coef() viser koefficienter. newdata skal være en dataframe med samme variabelnavn som i modellen. Et residual er observeret minus forudsagt.

model <- lm(dist ~ speed, data = cars)
coef(model)
forudsigelse <- predict(model, newdata = data.frame(speed = 20))
forudsigelse
plot(fitted(model), residuals(model), xlab = "Forudsagt dist", ylab = "Residual")
abline(h = 0, lty = 2)
justeret <- lm(mpg ~ wt + hp, data = mtcars)
coef(justeret)

Hældningen er cirka 3,93 feet pr. mph, og forudsigelsen er cirka 61,07 feet. I den multiple model fortolkes vægtkoefficienten ved fastholdt hp. Modellerne beskriver sammenhænge, som ikke i sig selv dokumenterer årsager.

Kopiér eventuelt løsningsforslaget til kodefeltet for at afprøve det.
